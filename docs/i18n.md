# Reader interface languages

The generated reader ships with English and Vietnamese interface labels. The
book itself is never translated: chapter titles, prose, captions, notes from
the EPUB, and metadata stay exactly as they appear in the source.

## How the switch works

- The language preference is stored in `localStorage` under
  `epub2web-ui-lang`.
- The first visit follows the system or browser language: a preferred
  Vietnamese locale (including regional tags such as `vi-VN`) selects
  Vietnamese, and every other language selects English. `navigator.languages`
  is checked first, with `navigator.language` and the `Intl` locale as
  fallbacks.
- The header language button shows the current code (`EN` or `VI`) and switches
  to the other language in one click. **Reading settings → Interface language**
  offers the same choice, and the two controls stay in sync.
- When the UI is Vietnamese, translated elements carry `lang="vi"` for screen
  readers. The document itself keeps the book’s language.

The default page is rendered in English, and `theme/assets/i18n.js` applies the
selected language. Without JavaScript, the reader stays usable in English.

## Source of truth

`epub2web/i18n.py` contains both message tables. Each generated page embeds
them as JSON in the `epub2web-ui-i18n` script element. The same table serves the
templates, `app.js`, and `annotations.js`, so a label only needs to be
translated once.

Templates mark leaf text and attributes with:

```html
<span data-i18n="home.startReading">Start reading</span>
<button data-i18n-aria-label="search.open" aria-label="Search the book">…</button>
```

Strings with variables use `data-var-*` attributes:

```html
<span data-i18n="contents.minutes" data-var-minutes="12">12 min</span>
```

`theme/assets/i18n.js` reads `data-i18n`, `data-i18n-html`,
`data-i18n-aria-label`, `data-i18n-title`, and `data-i18n-placeholder`, then
fills `{name}` placeholders from `data-var-*` or `data-i18n-vars` JSON.

Dynamic strings in `app.js` and `annotations.js` call
`window.epub2webI18n.t(key, values)`. A language change dispatches
`epub2web:languagechange`, so already-rendered search results, annotation
cards, and the continue-reading label are refreshed without a reload.

## Adding a language

1. Add the language code to `SUPPORTED_LANGUAGES` in `epub2web/i18n.py`.
2. Add a message table with every key from the English table.
3. Add an option to the interface-language fieldset in
   `epub2web/templates/dialogs.html`.
4. If the language needs glyphs outside the bundled Latin, Vietnamese, Greek,
   Cyrillic, Arabic, Hebrew, Devanagari, Thai, or CJK subsets, add the font
   subset and update `docs/fonts.md`.
5. Update `tests/test_i18n.py` expectations and run `make test`.

Keep translations in the voice of the reader interface: concise, direct, and
natural in the target language. Do not translate book text, chapter labels, or
metadata.
