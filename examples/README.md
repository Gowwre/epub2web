# Examples

A public-domain demo:

```bash
curl -L -o alice.epub \
  https://www.gutenberg.org/cache/epub/11/pg11-images.epub

epub2web alice.epub --serve
```

The generated site opens at `http://127.0.0.1:8000/`.

Other public-domain sources:

- Project Gutenberg: https://www.gutenberg.org/
- Standard Ebooks: https://standardebooks.org/

Only process books you have the right to use and share.
